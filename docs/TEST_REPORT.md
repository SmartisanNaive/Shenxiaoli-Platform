## 前端入口缺口与验证边界

- 课程导入、课程启停和教师维护有管理员 API，当前审核台没有课程管理界面。
- 添加收藏、屏蔽/解除屏蔽等部分能力有 API；页面提供收藏查看和取消，但缺少完整的添加及屏蔽管理入口。
- 本轮按既定计划验证这些 API 并记录入口缺口，没有将缺少的界面视为浏览器测试通过。
- 浏览器覆盖 Chromium 桌面及手机视口，不等同于已在真实 iOS Safari、Android 或生产穿透部署验收。
- 本地 worker 的服务商受理与 delivery 状态分开保存。签名回执使用测试数据；真实收件已验收，生产回执和生产备份演练仍需单独确认。
