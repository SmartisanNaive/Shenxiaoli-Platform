# 深小狸邮件模板

系统邮件统一采用深绿、米白和白色内容区，不依赖远程图片或字体。验证码以六位连续文本显示，
可直接复制；有效期及本次操作用途紧邻验证码。邮件摘要不显示验证码，通知邮件不包含私信正文。

## 模板与发送

`backend/src/email-template.ts` 提供 HTML 渲染，覆盖校园邮箱登录、当前/新校园邮箱验证、
辅助邮箱设置、新辅助邮箱验证、辅助邮箱恢复登录、账号注销、站内通知及发信测试。
动态标题、账号和正文均转义后插入 HTML；未知通知类型保留标题及正文，使用相同的基础排版。

所有发送路径经过 `backend/src/email.ts`，同时提交 HTML 和纯文本，保持原有收件人、
验证码校验、过期时间、幂等键及通知偏好规则。通知队列仍保存纯文本，在消费时渲染，
旧队列中的产品名称也会统一为“深小狸”，无需数据库迁移。

`RESEND_FROM` 继续配置已认证的发件地址；发送时保留该地址，将显示名统一为“深小狸”。
修改模板不会改变域名认证、垃圾邮件分类或投递策略。真实邮件客户端的显示以实际收信为准。

## 本地预览

从仓库根目录执行：

```bash
bun run mail:preview
```

在浏览器打开生成的 `.local-test/mail-preview/index.html`，选择邮件类型以及桌面或 375px
手机宽度；“查看完整 HTML”可查看单封邮件。全部样例使用合成邮箱和演示验证码，不发送邮件。
该目录忽略于 Git，修改渲染或样例后重新运行命令即可更新。

## 验证

```bash
cd backend
bun test test/email-template.test.ts
```

回归验证验证码只展示一次、操作说明保留、摘要不泄露验证码、动态 HTML 转义、纯文本版本、
旧队列名称转换，以及 Resend 的发件人、HTML、纯文本和幂等键参数。浏览器预览检查排版；
QQ 邮箱、校园邮箱及其他邮件客户端的收件展示需真实邮件验收。
